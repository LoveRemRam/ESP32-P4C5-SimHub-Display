# ESP32-P4C5 六代无线触摸屏

基于 ESP32-P4C5 (ESP32-P4 + ESP32-C5) 的赛车模拟器屏幕方案。
屏幕接收 SimHub 的仪表画面并显示，同时把手势触摸回传给电脑；
支持 74HC165 扩展按键与 WS2812B 灯带。

当前版本 **1.2.0.7 (build 7)**。固件与 SimHub 插件配套发布，请成对使用。

## 显示性能

| 指标 | 数值 |
| --- | --- |
| 屏幕刷新率 | 10 fps，画面以 100 ms 为节拍更新 |
| 端到端延迟 | 画面在电脑端产生到屏幕显示约 200 ms |

这套时序按仪表类内容设计：画面以数字、指针和状态指示为主，变化不剧烈，
10 fps 的刷新节奏配合约 200 ms 的端到端延迟不影响读表，
同时把屏幕侧的解码负载和总线占用控制在较低水平。

## 本版本能做什么

### 已在本项目硬件上实测通过

| 功能 | 说明 |
| --- | --- |
| 仪表画面 | 接收 SimHub 画面并显示，硬件 JPEG 解码，颜色已校正 |
| 触摸回传 | 单点、双指、四指、拖动、抬起，可直接操作游戏 |
| 原生 USB | 走 ESP32-P4 原生 USB，画面与触摸共用一条链路 |
| LED 灯带 | WS2812B 数据下发，支持颜色顺序、亮度与测试点亮 |
| 按键回传 | 74HC165 扩展按键，状态可回传给电脑 |

### 尚未实现

- **开机背景图上传功能尚未实现。**
  开机画面固定使用固件内置图片，无法通过插件替换。
- **无线桥接功能尚未实现。** 请使用有线 USB 连接。
- 其余外围功能（ADS1115 八轴、编码器、双离合、电池监控、BLE 手柄）
  已完成代码但未做实物验证，属于实验性质，不保证可用。

## 快速开始

1. **刷固件**：用 USB 线把板子接到 CH343 下载口，双击 `FlashGen6.exe`，
   选串口后点「开始刷机」。无需安装 Python 或 ESP-IDF，工具已内置运行库。
2. **装插件**：把 `SimHub插件\SimHubWiFiBridgeGen6.dll` 复制到 SimHub 安装目录，
   重启 SimHub 后在「设置 → 插件列表」中启用「SimHub 无线仪表桥」。
3. **导入设备模板**：SimHub → 模拟设备 → 添加新设备 → 从文件导入设备 →
   选择 `设备模板\SimHub无线协议桥.shdevicetemplate`。
4. **接线使用**：把板子插到 P4 原生 USB 口，打开 SimHub，屏幕即可显示仪表。

> **重要**：如果 SimHub 里已有内置的通用渲染设备，
> 请先把它**禁用**。否则它会占用设备的 USB 数据口，导致屏幕收不到画面。

详细步骤见包内 `刷机教程.txt` 与 `docs\使用说明.md`。

## 硬件要求

- OSPTEK ESP32-P4C5 核心板及配套底板
- 480x800 MIPI DSI 触摸屏（ST7102 屏驱动 + ST7123 触摸控制器）
- USB 数据线：刷机使用 CH343 口，日常使用 P4 原生 USB 口
- 可选：WS2812B 灯带、74HC165 扩展芯片
