================================================================================
  ESP32-P4C5 六代无线触摸屏 · 刷机与使用教程
================================================================================

  固件版本 ： 1.2.0.7   (build 7)
  插件版本 ： 1.2.0.7   (build 7)
  适用硬件 ： OSPTEK ESP32-P4C5 核心板 + 配套底板
  文档日期 ： 2026-10-07

  使用流程一共三步：
    1. 给屏幕板刷固件          （第二章）
    2. 在电脑上装 SimHub 插件  （第三章）
    3. 接线开用                （第四章）

  固件和插件必须配套。本包的固件和插件都是 1.2.0.7，请成对使用，
  不要用旧的插件配新的固件。

================================================================================
  二、给屏幕板刷固件
================================================================================

【第 1 步】接线

  用 USB 数据线把屏幕板接到电脑。

  插哪个口很重要：
    - 刷机请插 "CH343 下载口"（板子上标 CH343 / UART 的那个 Type-C）
    - 不要插 P4 原生 USB 口，那个口是给 SimHub 传数据用的，不能刷机

  首次使用如果电脑里看不到串口，需要先装一次 CH343 驱动
  （WCH 官网搜 "CH343SER" 下载安装即可，装完重新插拔一次）。


【第 2 步】打开工具

  双击 FlashGen6.exe。

  工具会自动找出电脑上的串口，并优先选中 CH343 那个。
  如果列表里没有你要的口，点一下"刷新"。

  界面顶部会显示当前固件包版本，正常应该看到 1.2.0.7。


【第 3 步】点"开始刷机"

  点蓝色的"开始刷机"按钮，确认后就开始写入。

  写入过程大约 20 到 40 秒，进度条走完会显示"刷机完成，设备已重启"。
  刷完后设备自动重启，屏幕亮起即表示成功。

  刷机过程中请不要：
    - 拔数据线
    - 关掉电脑或让电脑休眠
    - 给板子断电


--------------------------------------------------------------------------------
  刷机常见问题
--------------------------------------------------------------------------------

  Q：工具里看不到串口？
  A：先确认线插在 CH343 下载口，再装 CH343 驱动，然后点"刷新"。
     换一根数据线试试，有些线只能充电不能传数据。

  Q：点开始刷机后提示连接失败？
  A：把板子拔下来重插一次，确认没有别的软件（串口助手、Arduino IDE、
     ESP-IDF 监视器）正占着这个串口，然后重新刷。

  Q：刷完屏幕是黑的？
  A：先确认电脑端 SimHub 插件已经在运行并连上了这块板。
     开机时屏幕会显示一张待机图，收到画面后才切到仪表。
     如果始终没有待机图，重新刷一次。

  Q：提示"固件包不可用"？
  A：FlashGen6.exe 必须和 firmware 文件夹放在一起，不要单独把 EXE 拷走。


================================================================================
  三、在电脑上安装 SimHub 插件
================================================================================

  插件文件：SimHub插件\SimHubWiFiBridgeGen6.dll


【3.1 安装】

  1. 完全关闭 SimHub（右下角托盘图标也要退出，不是只关窗口）。
  2. 把 SimHubWiFiBridgeGen6.dll 复制到 SimHub 安装目录。
     也就是 SimHub.exe 所在的目录，如果你安装过自定义路径，请以实际位置为准。
  3. 启动 SimHub。

  重要：插件要放在 SimHub 的安装目录里，不是放在插件子文件夹里。


【3.2 启用】

  1. 打开 SimHub 的"设置"（Settings）。
  2. 找到"插件"（Plugins）列表。
  3. 在列表里找到"SimHub 无线仪表桥"，勾选启用。
  4. 启用后，左侧会出现这个插件的设置页，分四个标签：
     屏幕 / LED / 状态 / 模拟设备


【3.3 屏幕页设置】

  这里是让屏幕出画面的关键，逐项说明：

  屏幕列表
      默认已经有一条"屏幕 1"。点"添加屏幕"可以再加一块屏。
      每块屏一组独立配置，点"删除此屏幕"移除。

  名称
      给屏幕起个名字方便区分，比如"主屏"、"副屏"。

  IP
      该屏幕对应的 IP 地址。
      有线 USB 模式下这条通常不用管，插件会自动找到 USB 上的设备；
      走无线时填屏幕的 IP。

  端口
      默认 42100，一般不用改。

  亮度
      0 到 100% 的滑块，每块屏独立调节，属于软件调光。

  仪表来源（画面映射名）
      默认 SimHubDashRender。这个名字要和 SimHub 里
      对应设备的映射名一致。
      多屏显示不同仪表时，要给每块屏填不同实例的映射名。

  最大帧率
      每块屏独立限帧，默认 30。屏幕不大时调低一点能省电脑资源。

  JPEG 画质
      画质和带宽的取舍，数值越高越清晰、传输量越大。

  连接状态
      显示每块屏已发送帧数、上次变化的图块和错误信息，都是中文。
      这里出现帧数在涨，就说明画面已经在往屏幕发。


【3.4 开机背景图（本版本尚未实现）】

  开机画面固定使用固件内置的图片，不支持更换。
  插件里的"开机背景图"上传功能在本版本中尚未实现，
  相关设置即使操作也不会生效。

【3.5 LED 页】

  灯效由 SimHub 自己的 LED 配置算好颜色，插件负责把颜色下发到灯带。

  灯带像素数
      按实际灯带灯珠数量填。填错会出现灯带只亮一半或者后面不亮。

  亮度
      0 到 100% 的滑块。

  页面下方会显示灯带报告，可以点按钮做一次测试点亮，
  用来确认灯带接线和颜色顺序。

  颜色顺序（RGB / GRB 等）
      如果红色显示成绿色这类整体错位，就是颜色顺序不对，
      在插件和固件里改成一致的顺序即可。


【3.6 状态页】

  显示两种连接方式各自的状态：
    有线 USB   插上原生 USB 口后，这里应该显示"已连接"
    无线桥接   需要桥接端配合，目前还没闭环

  这一页还包含配对入口：进入配对模式、取消配对模式、确认配对，
  以及配对热点名称、配对码和已发现设备数。
  注意无线配对目前还没有实物验证过。


【3.7 模拟设备页】

  用来配置按键、轴、编码器等输入。
  注意这一页对应的硬件功能大多还没实物验证，详见第五章。


--------------------------------------------------------------------------------
  插件常见问题
--------------------------------------------------------------------------------

  Q：启动 SimHub 后没看到插件？
  A：确认 DLL 放在 SimHub 安装目录，不是子文件夹；确认 SimHub 是完全重启过的。

  Q：勾选了启用但屏幕不出画面？
  A：按顺序查 1) 屏幕板是不是插在 P4 原生 USB 口；
     2) 状态页有线 USB 是否显示"已连接"；
     3) 屏幕页的"连接状态"里帧数有没有在涨；
     4) "仪表来源"的名字和 SimHub 里对应设备的映射名是否一致。

  Q：触摸没反应？
  A：确认固件已经刷到 1.2.0.7，并且状态页显示有线 USB 已连接。


================================================================================
  四、接线与开机使用
================================================================================

  板子上有两个 Type-C 口，用途完全不同，别插错：

    CH343 下载口    只用于刷机，插上电脑是为了升级固件
    P4 原生 USB 口  平时使用插这个，画面和触摸都走这里


【正常使用顺序】

  1. 屏幕板插上 P4 原生 USB 口，连到电脑。
  2. 打开 SimHub，确认插件已启用。
  3. 屏幕显示开机背景图，随后切到 SimHub 仪表画面。
  4. 直接在屏幕上点按操作游戏。

  插件不依赖固定 COM 号，它是按设备硬件 ID（VID_303A / PID_4005）
  自动找设备的，所以插拔后换了 COM 号也不影响，不用手动改配置。


【屏幕上的操作】

  开机图界面
      在屏幕上滑动可以进入 WiFi 配对页。

  仪表界面
      按住右上角约 1.5 秒，可以重新打开 WiFi 配对页。
      这个热区是隐形的，轻点不会触发，正常游戏时不会误触。

  WiFi 配对页
      点击按键、网络列表和按钮完成操作。


================================================================================
  五、现在能做什么（重要）
================================================================================

  下面分成三组，请按这个口径理解，不要把后面两组当成成品功能。
  "已验证"是在这套硬件上亲手测过、确认可用的。


【5.1 已验证可用】

  屏幕显示
    接收电脑端发来的 SimHub 仪表画面并显示，画面经过硬件 JPEG 解码。
    颜色已经校正过，不会出现红绿颠倒。

  触摸回传
    单点、双指、四指触摸，以及拖动和抬起，都能回传给 SimHub。
    可以直接在屏幕上操作游戏里的按键和拨杆。

  原生 USB 数据链路
    走 P4 原生 USB 口，带宽高、延迟低，画面和触摸都走这一条。
    数据带长度头，断线和异常包能自动恢复。

  LED 灯带
    WS2812B 灯带数据的接收和显示，包含颜色顺序修正、亮度控制和测试灯。

  有线 / 无线自动切换
    插上原生 USB 口就自动走有线，拔掉后如果桥接配对成功就走无线。
    两个同时可用时优先有线，因为更稳定。

  SimHub 插件
    屏幕列表、亮度、帧率、画质、背景图上传、LED 设置、状态显示
    这些页面功能已实现并可正常使用。


【5.2 已实现但未在实物上验证】

  以下功能代码已完成、编译通过，但还没有对应的实物测试记录，请谨慎使用：

  74HC165 按键扩展
    最多支持多片 74HC165 级联扩展按钮输入，目前只做过自检，
    没有逐位验证过编号和实际手感。

  ADS1115 八轴输入
    两片 ADS1115 提供 8 路模拟轴（油门、刹车、离合等）。
    芯片尚未接实物验证采样和方向。

  旋转编码器
    代码支持多路旋转编码器，方向与每格步进还没用机械编码器实测。

  双离合踏板
    双离合的联动逻辑已写好，缺少实体轴输入验证结合点。

  配置掉电保存
    配置写 NVS，理论上断电不丢，还需要做断电重启验证。

  电池与充电监控
    BQ25756E 芯片的寄存器读取和电量页显示已实现，
    芯片还没到货，没有实物确认。同样，充电 10A / 放电 30A 属于设计目标，
    必须以实际保护板和散热实测为准。

  BLE 蓝牙手柄
    P4 通过板载 C5 的蓝牙，对外表现为一个 BLE 游戏手柄。
    配对、按键、轴、重连和重配都还需要在 Windows 和手机上验证。

  模拟设备页面
    插件里的"模拟设备"页可以配置按键、轴、编码器等，
    页面逻辑已优化，但还没有在 SimHub 里做长时间的逐项实测。


【5.3 尚未完成，不要期待】

  双板无线桥接
    无线桥接端只有骨架，配对状态机、设备路由和回传还没有闭环。
    要真正实现"屏幕无线连电脑"，还需要第二块板做桥接端，目前无法验证。
    所以现阶段请按有线 USB 的方式使用。


================================================================================
  六、引脚对应表
================================================================================

  引脚号是 ESP32-P4 的 GPIO 编号。带"固定"的引脚由核心板和底板占用，
  不能改接，改动会导致无法启动或屏幕点不亮。


【6.1 底板固定占用（不要改动）】

  功能                      引脚                        说明
  ------------------------------------------------------------------------
  P4 <-> C5 通信            GPIO6 / 14 / 15 / 16 /      核心板内部 SDIO
                           17 / 18 / 19 / 54           连接板载 C5 无线芯片
  LCD 背光                  GPIO33
  背光升压                  GPIO20
  屏幕 TE                   GPIO32
  CH343 调试串口 TX         GPIO37                      刷机口
  CH343 调试串口 RX         GPIO38                      刷机口
  触摸屏 I2C0 SDA           GPIO7                       触摸芯片地址 0x55
  触摸屏 I2C0 SCL           GPIO8                       触摸芯片地址 0x55
  原生 USB                  GPIO24 / GPIO25 + DM / DP   接电脑数据口
  屏幕 MIPI DSI             DSI_CLK_P/N、D0_P/N、       屏幕专用差分线，
                           D1_P/N                       不能用普通 GPIO 代替


【6.2 本固件额外占用（外接模块用）】

  功能                      引脚                        说明
  ------------------------------------------------------------------------
  ADS1115 I2C1 SDA          GPIO49                      8 轴模拟输入
  ADS1115 I2C1 SCL          GPIO50
  ADS1115 中断              GPIO51                      预留，固件暂未用中断
  ADS1115 地址              0x48 / 0x49                 两片芯片

  74HC165 并口加载 PL       GPIO52                      按键扩展
  74HC165 时钟 CP           GPIO48
  74HC165 数据 DATA         GPIO47

  WS2812B 灯带数据          GPIO46

  电源芯片 I2C1 SDA         GPIO49                      与 ADS1115 共用
  电源芯片 I2C1 SCL         GPIO50                      与 ADS1115 共用
  电源芯片中断              GPIO5                       预留
  BQ25756E 地址             0x6A                        7 位地址


【6.3 接口位置速查】

  刷机口      CH343 那个 Type-C
  数据口      P4 原生 USB 那个 Type-C（接电脑跑 SimHub）
  8 轴接口    8 个 3PIN 座，分别对应 ADS1115 的 8 个通道
  灯带接口    WS2812B 5PIN 座
  按键接口    74HC165 5PIN 座


================================================================================
  七、刷机与使用注意事项
================================================================================

  1. 固件和插件版本要一致。本包两者都是 1.2.0.7。
  2. 刷机时用质量好一点的数据线，劣质线是刷机失败最常见的原因。
  3. 刷机不要和别的串口软件抢同一个口。
  4. 平时使用要插 P4 原生 USB 口，不要插 CH343 口。
  5. 插件要放进 SimHub 安装目录并完全重启 SimHub 才会生效。
  6. 屏幕、触摸以外的功能（轴、按键、电池、蓝牙）还在等待实物验证，
     装机前请先按第五章的口径确认哪些功能真的可用。
  7. 无线桥接尚未闭环，请先用有线 USB 方式。
