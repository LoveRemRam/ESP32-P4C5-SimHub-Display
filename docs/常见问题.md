# 常见问题

按问题出现的环节分为刷机、插件和显示三类。

## 刷机

### 刷机工具里看不到串口

1. 确认数据线插在 **CH343 下载口**，不是 P4 原生 USB 口。
2. 安装 CH343 驱动后重新插拔设备，再点工具里的「刷新」。
3. 换一根数据线测试。部分线缆只支持充电，不支持数据传输。

### 点击开始刷机后提示连接失败

- 拔下设备重新插入后再试。
- 关闭可能占用该串口的软件，例如串口助手、Arduino IDE、ESP-IDF 监视器。
- 确认没有其他刷机工具正在使用同一端口。

### 提示「固件包不可用」

`FlashGen6.exe` 必须与 `firmware` 文件夹放在同一目录下。
请勿单独拷贝 EXE 文件。

### 刷机中途失败或中断

重新执行一次刷机即可，重复刷写不会损坏设备。
若多次失败，优先更换数据线，并确认电脑 USB 供电稳定。

## 插件

### 启动 SimHub 后看不到插件

- 确认 `SimHubWiFiBridgeGen6.dll` 放在 SimHub 的**安装目录**，而不是子文件夹。
- 确认 SimHub 已完全退出后重新启动，包括右下角托盘图标。
- 在「设置 → 插件列表」中确认插件未被禁用。

### 插件已启用但屏幕不出画面

按顺序检查：

1. 屏幕板是否插在 **P4 原生 USB 口**。
2. 插件「状态」页中，有线 USB 是否显示「已连接」。
3. 插件「屏幕」页的「连接状态」里，已发送帧数是否在增长。
4. 「仪表来源」填写的名称，是否与 SimHub 中对应设备的映射名一致。

### 触摸没有反应

- 确认固件版本为 1.2.0.7。
- 确认插件「状态」页显示有线 USB 已连接。
- 确认当前不在 WiFi 配对页，仪表界面下触摸才回传给游戏。

### 灯带只亮一部分或后段不亮

检查插件「LED」页中的「灯带像素数」是否与实际灯珠数量一致。

### 灯带颜色错位（例如红色显示成绿色）

颜色顺序不匹配。在插件「LED」页选择正确的颜色顺序，
并确保与固件中的设置一致。

## 显示与画面

### 刷完屏幕是黑的

- 确认电脑端 SimHub 插件已运行并连接到设备。
- 开机时屏幕会先显示待机图，收到画面后才切换到仪表。
- 若始终没有待机图，请重新刷写固件。

### 画面颜色异常

正常情况不应出现红绿颠倒，固件已做颜色顺序校正。
若出现异常，请确认使用的是配套版本的固件与插件。

### 插拔后设备连不上

插件通过设备硬件 ID 自动定位设备，不依赖固定 COM 号。
若插拔后无法连接，先在插件「状态」页确认连接状态，必要时重启 SimHub。

### 屏幕显示的内容与预期不一致

检查「仪表来源」的映射名。多屏显示不同仪表时，每块屏需填写
对应实例的映射名，不能共用同一个名字。

## 无线相关

### 无线连接不可用

无线桥接功能尚未闭环，现阶段请统一使用有线 USB 方式连接。
