# 引脚说明

引脚号为 ESP32-P4 的 GPIO 编号。

标注为「固定」的引脚由核心板与底板占用，不可改接，
否则会导致设备无法启动或屏幕不亮。

## 底板固定占用

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| P4 ↔ C5 通信 | GPIO6 / 14 / 15 / 16 / 17 / 18 / 19 / 54 | 核心板内部 SDIO，连接板载 C5 无线芯片 |
| LCD 背光 | GPIO33 | |
| 背光升压 | GPIO20 | |
| 屏幕 TE | GPIO32 | |
| CH343 调试串口 TX | GPIO37 | 刷机口 |
| CH343 调试串口 RX | GPIO38 | 刷机口 |
| 触摸屏 I2C0 SDA | GPIO7 | 触摸芯片地址 0x55 |
| 触摸屏 I2C0 SCL | GPIO8 | 触摸芯片地址 0x55 |
| 原生 USB | GPIO24 / GPIO25 + DM / DP | 接电脑数据口 |
| 屏幕 MIPI DSI | DSI_CLK_P/N、D0_P/N、D1_P/N | 屏幕专用差分线，不能用普通 GPIO 代替 |

## 本固件额外占用

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| ADS1115 I2C1 SDA | GPIO49 | 8 轴模拟输入 |
| ADS1115 I2C1 SCL | GPIO50 | |
| ADS1115 中断 | GPIO51 | 预留，固件暂未使用中断 |
| ADS1115 地址 | 0x48 / 0x49 | 两片芯片 |
| 74HC165 并口加载 PL | GPIO52 | 按键扩展 |
| 74HC165 时钟 CP | GPIO48 | |
| 74HC165 数据 DATA | GPIO47 | |
| WS2812B 灯带数据 | GPIO46 | |
| 电源芯片 I2C1 SDA | GPIO49 | 与 ADS1115 共用 |
| 电源芯片 I2C1 SCL | GPIO50 | 与 ADS1115 共用 |
| 电源芯片中断 | GPIO5 | 预留 |
| BQ25756E 地址 | 0x6A | 7 位 I2C 地址 |

## 接口位置速查

| 接口 | 位置 |
| --- | --- |
| 刷机口 | CH343 对应的 Type-C |
| 数据口 | P4 原生 USB 对应的 Type-C |
| 8 轴接口 | 8 个 3PIN 座，分别对应 ADS1115 的 8 个通道 |
| 灯带接口 | WS2812B 5PIN 座 |
| 按键接口 | 74HC165 5PIN 座 |

## 说明

- 8 路模拟轴全部走外置 ADS1115，不使用 P4 内部 ADC。
- ADS1115 与电源芯片共用 I2C1，两者地址不冲突。
- 屏幕使用 MIPI DSI 差分信号，需使用专用走线，不可用普通 GPIO 替代。
- GPIO5 在当前设计中作为电源芯片中断预留，固件尚未启用。
