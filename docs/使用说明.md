# 使用说明

本文档说明固件刷写、SimHub 插件安装与设置，以及屏幕的日常操作方式。

固件版本：1.2.0.7 (build 7)
插件版本：1.2.0.7 (build 7)

固件与插件必须配套，请成对使用，不要只更新其中一个。

## 一、刷写固件

### 准备工作

- USB 数据线一根（需支持数据传输，仅充电线不可用）
- 首次刷写需安装 CH343 串口驱动

### 操作步骤

1. 用数据线把屏幕板接到电脑的 **CH343 下载口**。

   板上两个 Type-C 口用途不同：CH343 口用于刷机，P4 原生 USB 口用于日常传数据。
   刷机请务必使用 CH343 口。

2. 双击 `FlashGen6.exe`。

   工具会自动枚举电脑上的串口，并优先选中 CH343 对应的端口。
   若列表中没有目标端口，点击「刷新」重新枚举。

3. 确认界面顶部显示的固件版本为 1.2.0.7。

4. 点击「开始刷机」，在确认对话框中点击确定。

5. 等待进度条走完，出现「刷机完成，设备已重启」即表示成功。

   刷写过程约 20 到 40 秒。期间请勿拔线、断电，或让电脑进入休眠。

### 刷写注意事项

- 刷写前请关闭串口助手、Arduino IDE、ESP-IDF 监视器等可能占用串口的软件。
- 若提示连接失败，可拔下设备重新插入后再试一次。
- `FlashGen6.exe` 需与 `firmware` 文件夹保持在一起，不可单独拷贝。

## 二、安装 SimHub 插件

插件文件：`SimHub插件\SimHubWiFiBridgeGen6.dll`

### 安装

1. 完全退出 SimHub，包括右下角托盘图标，确认进程已结束。
2. 把 `SimHubWiFiBridgeGen6.dll` 复制到 SimHub 的**安装目录**。
   注意是安装目录，不是插件子文件夹。
3. 启动 SimHub。

### 启用

1. 打开 SimHub 的「设置」。
2. 进入「插件」列表。
3. 找到「SimHub 无线仪表桥」，勾选启用。
4. 启用后插件设置页会出现在左侧，共四个标签页：
   **屏幕 / LED / 状态 / 模拟设备**。

## 三、插件设置项

### 屏幕页

这一页决定屏幕能否正常出画面。

| 设置项 | 说明 |
| --- | --- |
| 屏幕列表 | 默认已包含「屏幕 1」。点击「添加屏幕」可增加多块屏，每块屏拥有独立配置；「删除此屏幕」移除当前屏幕。 |
| 名称 | 屏幕的显示名称，便于区分，例如「主屏」「副屏」。 |
| IP | 该屏幕对应的 IP 地址。有线 USB 模式下通常无需填写，插件会自动定位 USB 设备；使用无线时填写屏幕 IP。 |
| 端口 | 默认 42100，一般无需修改。 |
| 亮度 | 0 到 100% 的滑块，逐屏独立，属于软件调光。 |
| 仪表来源（画面映射名） | 默认为 ``SimHubDashRender``，需与 SimHub 中对应设备的映射名一致。多屏显示不同仪表时，为每块屏填写各自实例的映射名。 |
| 最大帧率 | 逐屏限帧，默认 30。屏幕较小时适当调低可降低电脑负载。 |
| JPEG 画质 | 画质与带宽的取舍，数值越高画面越清晰、传输量越大。 |
| 连接状态 | 显示每块屏已发送帧数、最近发生变化的图块及错误信息。帧数持续增长表示画面正在下发。 |

### 开机背景图

屏幕页上方设有「开机背景图」区域。选择一张 480x800（或任意比例，插件会自动缩放）
图片并上传，该图会作为 SimHub 接管前的屏幕底图。

### LED 页

灯效颜色由 SimHub 自身的 LED 配置计算，插件负责把计算好的颜色下发到灯带。

| 设置项 | 说明 |
| --- | --- |
| 灯带像素数 | 按实际灯珠数量填写。填错会出现灯带只亮一部分或后段不亮。 |
| 亮度 | 0 到 100% 的滑块。 |
| 颜色顺序 | 可选 RGB / GRB 等。若出现红绿整体错位，说明顺序不匹配，需与固件保持一致。 |

页面下方会显示灯带报告，并提供测试点亮按钮，用于确认灯带接线与颜色顺序。

### 状态页

分别显示两种连接方式的状态：

| 连接方式 | 说明 |
| --- | --- |
| 有线 USB | 插入 P4 原生 USB 口后应显示「已连接」 |
| 无线桥接 | 需要桥接端配合，目前尚未闭环 |

该页同时提供配对入口：进入配对模式、取消配对模式、确认配对，
并显示配对热点名称、配对码与已发现设备数。无线配对功能尚未经过实物验证。

### 模拟设备页

用于配置按键、轴与编码器等输入。该页对应的硬件功能大多尚未完成实物验证，
详见[功能状态说明](#五功能状态说明)。

## 四、接线与日常操作

### 两个 Type-C 口的区别

| 接口 | 用途 |
| --- | --- |
| CH343 下载口 | 仅用于刷写固件 |
| P4 原生 USB 口 | 日常使用，画面与触摸数据均走此口 |

### 正常使用顺序

1. 将屏幕板插入 **P4 原生 USB 口**并连接电脑。
2. 打开 SimHub，确认插件已启用。
3. 屏幕显示开机背景图，随后自动切换到 SimHub 仪表画面。
4. 直接在屏幕上点按操作游戏。

插件通过设备硬件 ID 自动定位设备，不依赖固定 COM 号，
因此插拔后端口号变化不会影响使用，无需手动调整配置。

### 屏幕上的操作

| 界面 | 操作 |
| --- | --- |
| 开机图界面 | 在屏幕上滑动可进入 WiFi 配对页 |
| 仪表界面 | 按住右上角约 1.5 秒可重新打开 WiFi 配对页。该热区为隐形热区，轻点不会触发，正常游戏时不会误触 |
| WiFi 配对页 | 点击按键、网络列表与按钮完成操作 |

## 五、功能状态说明

各项功能的完成程度分为三类，请按此口径理解。

### 已实现并通过实物验证

- 屏幕显示（含颜色顺序校正）
- 触摸回传（单点、双指、四指、拖动、抬起）
- 原生 USB 数据链路（含断线与异常包恢复）
- LED 灯带（颜色顺序、亮度、测试灯）
- 有线/无线自动切换，同时可用时优先有线
- SimHub 插件的屏幕列表、亮度、帧率、画质、背景图上传、LED 设置与状态显示

### 已实现，尚未完成实物验证

- 74HC165 按键扩展（仅通过自检，未逐位验证）
- ADS1115 八轴输入（未验证采样与方向）
- 旋转编码器（未验证方向与步进）
- 双离合踏板（未验证结合点）
- 配置掉电保存（未做断电重启验证）
- 电池与充电监控（芯片尚未到货）
- BLE 蓝牙手柄（未在 Windows 与手机端验证）
- 插件「模拟设备」页（未做长时间实测）

### 尚未完成

- 双板无线桥接。桥接端仅完成骨架，配对状态机、设备路由与回传尚未闭环。
  现阶段请使用有线 USB 方式。
